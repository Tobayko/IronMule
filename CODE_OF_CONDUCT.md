# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The short version:

- Be civil. Disagreement about a measurement, a design or a number is welcome;
  contempt for the person holding it is not.
- Criticise the claim, not the author. "This ratio has no control arm" is useful.
  "You clearly don't understand benchmarking" is not.
- Harassment, discrimination and personal attacks are not tolerated, in issues,
  pull requests, commit messages or anywhere else this project is discussed.
- Assume the other person measured in good faith until the data says otherwise.

## Reporting

Report unacceptable behaviour by
[opening a private security advisory](https://github.com/Tobayko/IronMule/security/advisories/new),
which is the only private channel this repository has. Reports are read by the
maintainer and are not shared further.

Consequences are proportionate and at the maintainer's discretion: an ordinary
first step is a request to change the behaviour, a repeated or severe one is a
block.
