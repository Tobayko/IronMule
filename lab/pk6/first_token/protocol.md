# First-token experiment on one A100

Codex proposed this candidate after joining the historical PR 57 client and native traces. Each of six 32-client waves waited for one packed call with both prompt lengths. The hypothesis is that returning the first 17 picks before processing the remaining 15 can advance median first content while maintaining useful work per second. This is a developer experiment. The training archive must keep this attribution.

Freeze before leasing. Use one NVIDIA A100-SXM4-80GB and a verified Qwen3-32B Q4_K_M GGUF. Start with PR 57 at f3a69741f7a466ffc144a87b0395f4bfdb6e9b50, automatic local calibration, PS1 and PK6 enabled, SV5 and DH2 off. Apply the accompanying lab patch in an isolated checkout. Both arms use that tree. Enable early delivery only in candidate processes. It applies to an idle packed step containing 32 real jobs split evenly across two prompt lengths at least fourfold apart. It submits the 16 short prompts and one long prompt, emits their picks, then submits the remaining 15. KV sequence IDs retain their owners.

Run four fresh production HTTP processes on the same device in R1/C1/C2/R2 order. Use the same persistent calibration state. Each process uses the standard streaming warmup and three 32-client performance waves, including the first. Each request has a cap of 32 generated tokens. The matching arms receive the same fresh prompts by position, using base seeds 260113 and 260177 for the two pairs. Two 8-client waves per process include the existing 18-case factual check. Trace every arm. Timing includes client, server, CPU Pilot, sampling and delivery. Startup is reported separately.

Require four successful quality-gated starts, each with the same 32-sequence qualification, all factual checks 18/18, full fixed output work and matching input lengths in every pair. Check that the native traces bind the streamed request IDs and actually show two calls on candidate waves and one on reference waves. Evaluate paired ratios over three waves within each start pair. For each of both pairs require median throughput ratio at least 1, first-content p50 ratio at most 0.90 and p95 ratio at most 1. Report individual waves and worst-client timing too. Report output digests separately from factual correctness. Incomplete timing, identity or work fails the test. A pass nominates a locally qualified holdout and rollback test before any normal serving change. A failed gate retains the reference and the negative data.

Use the existing cumulative USD 20 ledger. Reserve at most 65 minutes at USD 2.50/hour plus the existing 10-minute cleanup tail (USD 3.125). Stop and remove the pod as soon as measurements have been copied, on an unrecoverable setup failure or at the deadline. Do not extend this lease. The independent local and pod watchdogs enforce the cutoff. No new competitor server is needed for this paired mechanism test.
